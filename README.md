# 连鹏磊 · 开发者作品集

以研究型开发者为主线的静态作品集，覆盖截至 2026-10-23 的全部 7 个公开 GitHub 仓库。使用原生 HTML / CSS / JavaScript，不需要安装前端依赖，也不发送分析或追踪请求。

## 预览

直接打开 `index.html`，或在本目录运行：

```sh
python -m http.server 18473 --bind 127.0.0.1
```

访问 http://127.0.0.1:18473 。项目支持分类筛选、文本搜索、项目详情弹窗、键盘操作和响应式布局。概念图由 SVG 生成，不是产品截图或真实实验结果。

## 编辑

- `projects.js`：全部项目内容、标签、架构路径、验证范围及来源链接。
- `app.js`：筛选、搜索、弹窗及 SVG 图形。
- `styles.css`：视觉样式与断点。
- `index.html`：首页文案、导航、技术方向和关于区。
- `PROJECT_ANALYSIS.md`：完整分析与内容取舍。

公开仓库数量为快照，网页不会自动查询 GitHub。新增项目时同步更新数据、计数和分类文案。网站按本人要求展示姓名“连鹏磊”，不包含学校、联系方式、数据下载口令、研究对象信息或日志。未虚构工作经历、商业客户、性能指标、论文发表状态或项目上线状态。

## 静态部署

页面使用相对路径，可放到 GitHub Pages 或任何静态服务器。部署目录只需要 `index.html`、`styles.css`、`app.js`、`projects.js`；不需要上传相邻的研究缓存或其他项目资料。线上地址：https://lpl969.github.io/portfolio/ 。站点通过 main 分支根目录发布到 GitHub Pages。
