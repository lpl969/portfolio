# 连鹏磊的个人主页

线上地址：https://lpl969.github.io/portfolio/

参考学术主页的导航与侧栏布局，使用原生 HTML、CSS、JavaScript 实现首页、论文、项目和公开简历四个视图。支持手机适配、深色模式、项目筛选和搜索、简历打印。无追踪脚本或外部字体依赖。

## 内容维护

- `index.html`：个人介绍、动态、论文、经历与公开简历。
- `projects.js`：7 个研究和工程项目的介绍及源码入口。
- `styles.css`：学术主页风格、移动布局、深色主题及打印样式。
- `app.js`：导航、筛选、主题切换和打印。
- `portrait.jpg`：本人提供的简历照片，已重新编码以去除原文件元数据。
- `portfolio-qr.png` / `portfolio-qr.svg`：线上地址二维码。

本地预览可直接打开 index.html，也可运行 `python -m http.server 18473 --bind 127.0.0.1`。

## 发布

GitHub Pages 从 main 分支根目录发布，`.nojekyll` 禁用 Jekyll 处理。链接与二维码不随网页内容更新而变化。

内容依据本人提供的简历及公开源码。论文在投状态明确标注，实验数据注明来自简历，不代表本次重新复现。公开页不含电话、私人邮箱、政治面貌、具体住址或原始简历下载。姓名、照片、教育及职业经历用于本人授权的主页展示。
